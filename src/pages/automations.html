aertun automate templates
aertun automate add TEMPLATE
aertun automate mode ID ask
aertun automate runs
aertun automate approve RUN
  • Watch records what the rule would do.
  • Ask waits for a person to approve each run.
  • Act does it at once, within an hourly limit per rule, so one noisy source cannot suspend everybody.

Whoever wrote a rule does not approve the runs it holds. Approving a run that acts on people's access takes an administrator of all of aertun. Rules about sign-ins can tell an office or a VPN from anywhere else:

aertun geo network add 198.51.100.0/24 head-office --kind office
aertun geo status
