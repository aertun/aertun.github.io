aeroprove automate mode ID ask
aeroprove automate runs
aeroprove automate approve RUN
  • Watch records what the rule would do.
  • Ask waits for a person to approve each run.
  • Act does it at once, within an hourly limit per rule, so one noisy source cannot suspend everybody.

Whoever wrote a rule does not approve the runs it holds. Approving a run that acts on people's access takes an administrator of all of AeroProve. Rules about sign-ins can tell an office or a VPN from anywhere else:

aeroprove geo network add 198.51.100.0/24 head-office --kind office
aeroprove geo status
