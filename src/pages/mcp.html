The agent interface speaks MCP over standard input and output, as the person whose token it carries, with that person's access and no more. An agent loads only the operations it searches for.

OperationWhat it does
list_findingsthe finding queue, most urgent first
read_findingone finding: why it ranks, its evidence, and what has been decided
propose_finding_decisionsuggest a decision on a finding for a person to make
incident_statusopen incidents: which clocks are running, late or not started
detection_statswhat each rule has been worth, and what the numbers suggest changing
vuln_planthe smallest upgrades that clear the most vulnerability risk
estate_summaryhow many people are at each level of risk, as numbers, never names
findfind a screen by words

An agent reading events is reading text an attacker chose, so nothing on this interface changes who may do what, approves an action, or reaches another platform.
