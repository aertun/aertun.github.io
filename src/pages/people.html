aeroprove scim token
aeroprove scim map security-analysts analyst
aeroprove scim status

The identity provider adds, changes and removes people; a group is mapped to a role or a job.

Tokens

aeroprove token issue ci --principal ci-bot
aeroprove token list
aeroprove token revoke ID
aeroprove token stale

A token is shown once and stored only as a hash. An administrator's token takes a second administrator.
